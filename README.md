A furious competition judge finally snaps — one short rant, 355 characters, about the terrible entries he has to read every single day:

> I have read ten thousand of your 'rants.' Ten thousand! Half are 'Mondays, am I right?' — groundbreaking, truly, nobody has ever disliked a Monday. The other half are love letters to a printer written by people who have clearly never met one. One of you submitted a grocery list. A GROCERY LIST. With coupons. I am not angry, I am professionally deceased.

The program writes that rant to `/output/entry.txt` for make.fun's "Angry Judge: The Short Rant Contest" bounty. It self-checks the 1–400 character gate before writing, then reads the file back to verify it landed exactly as intended.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`.
